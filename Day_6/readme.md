# Day 6 - Python for Data Science

## Overview

Day 6 focused on learning the fundamentals of **NumPy** and **Pandas**, two of the most important Python libraries for Data Science and Machine Learning. The goal was to understand how to work with arrays, load datasets, explore data, and perform basic data analysis.

---

## Topics Covered

### NumPy
- Creating 1D and 2D arrays
- Array indexing and slicing
- Array arithmetic operations
- Mathematical functions
- Array reshaping

### Pandas
- Series and DataFrames
- Reading CSV files
- Exploring datasets
- Selecting rows and columns
- Filtering data
- Finding missing values
- Summary statistics

---

## Mini Project

### Student Performance Analysis

The project includes:

- Loading the student dataset using Pandas
- Displaying dataset information
- Calculating average marks for each subject
- Identifying the top 5 performing students
- Finding students scoring below the average
- Displaying the total number of students
- Saving the processed dataset as a new CSV file
