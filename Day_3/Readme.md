# Number Analysis Tool

## Features

The program accepts a number from the user and performs the following operations:

- Check whether the number is Even or Odd
- Check whether the number is Prime
- Count the total number of digits
- Reverse the number
- Check whether the number is a Palindrome

All results are displayed in a user-friendly format.
