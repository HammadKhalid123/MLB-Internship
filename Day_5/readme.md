# Library Management System

## Features

- Add Book
- View All Books
- Search Book
- Borrow Book
- Return Book
- Remove Book

## Data Storage

Book records are stored permanently in a **books.json** file.

## Challenges Faced

- Understanding inheritance and organizing the project using multiple classes.
- Managing JSON data while updating book records.
- Handling invalid user input.

## Solutions Implemented

- Used separate **Book** and **Library** classes.
- Applied inheritance to reduce code duplication.
- Used JSON for persistent storage with exception handling.

## Conclusion

Day 5 helped me understand how OOP makes programs more organized, reusable, and easier to maintain. I also learned how to build a real-world application using classes, inheritance, and JSON.
