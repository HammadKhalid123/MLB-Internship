# Image Processing App

A simple **Streamlit + OpenCV** application for basic image processing.

## Features

* Upload an image
* Choose different processing options
* Display original and processed images
* Save the processed image

## Technologies

* Python
* Streamlit
* OpenCV
* NumPy
* Pillow

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Processing Options

* Grayscale
* Blur
* Edge Detection
* Rotation
* Brightness & Contrast
* Sharpening
* Flip
* Thresholding

## Output

Processed images are saved in the `outputs/` folder.
